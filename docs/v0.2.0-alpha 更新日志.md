## 🎉 新内容

### 多人对战：三种板子

对战不再限于 1v1，启动器「开始对战」后可选板子：

| 板子 | 人数 | 队伍配置 |
| --- | --- | --- |
| **双人对决** | 2 | 队伍A vs 队伍B（即原 1v1） |
| **三方混战** | 3 | 三人各自为队，最后存活者获胜 |
| **双人组队** | 4 | 队伍A（座位 0、2）vs 队伍B（座位 1、3），队友交错落座 |

- **随机落座**：选人阶段不显示队伍；选人结束后随机分配座位与先手，因此 2v2 中「谁和谁一队」也是随机的。
- **队伍胜负**：组队局需同队全员死亡才败北，队友共享胜利；混战局最后存活者获胜；全员同时死亡判平局。
- **回合轮转**：按座位顺序依次进行回合，自动跳过已死亡玩家。
- 板子配置位于 `data/boards.json`，新增板子无需改代码。

### 动态玩家面板

- 2 人 1×2、3 人 1×3、4 人 2×2 布局，按板子人数自动生成。
- 组队/混战局面板标题与「当前回合」显示队伍名（如「玩家3·里莫　[队伍A]」）。
- 终局界面组队局显示「队伍X 获胜！」并列出全部成员。

## 📜 规则口径变更（重要）

以下规则经确认后以本次实现为准，规则文档已同步更新：

1. **初始手牌 = 摸牌数值（默认 5）**——此前实现误用存牌数值（3 张），本版本修正为开局按各自摸牌数值发牌。弃牌阶段上限仍为存牌数值，不受影响。
2. **「其他玩家」默认包含队友**——卡牌/技能描述未写「敌方」时，目标范围包含队友（如〖疫医〗比较全体生命值）；只有明确写「敌方」的效果才排除同队。
3. **单体目标可以选队友**——「任一其他存活玩家」只排除自己与已死亡/濒死者；敌我过滤只发生在多目标效果（`all_enemies` = 所有非同队玩家，`all_allies` = 所有同队玩家含自己）。
4. **濒死救援询问所有人**——从濒死者起按座位顺序依次询问全部存活玩家（含敌方），且**允许救敌方**；询问救援不影响任何技能的目标选择。
5. **陷阱队友可见**——自己与队友可见陷阱区内容，敌方仅可见数量。

## 🏗 引擎机制扩展

1. **板子系统** — 新增 `data/boards.json`：定义人数、队伍与座位归属；加载时校验座位完整覆盖、越界、重复占用与队伍 id 唯一性；启动器按配置动态生成选择列表。
2. **队伍模型** — `PlayerData` 新增 `team_id` / `seat_index`；选人结束后随机打乱角色→座位映射，队伍由板子座位反查，同局内不再变动。
3. **目标语义按队伍解析** — 目标解析函数支持显式来源玩家参数；`all_enemies` 按「非同队」过滤，`all_allies` 按「同队含自己」过滤；1v1 下与旧语义完全等价，现有卡牌/技能数据零改动。
4. **队友陷阱不误触发** — 行为触发型陷阱在触发判定前检查「触发者不是陷阱主人的队友」，2v2 中队友行为不再引爆自家陷阱。
5. **队伍胜负判定** — 死亡检查按存活队伍数结算；全员同时死亡判平局；终局记录胜利队伍名与成员列表。
6. **回合安全网** — 连续跳过上回合加计数上限防死循环；全员死亡时回合推进熔断；新增 `_end_turn_if_current_dead()`，当前行动玩家死亡（自伤/状态致死）时立即结束其回合并移交下一名存活玩家。

## 🖥 UI 调整

- **启动器板子选择** — 「开始对战」弹出板子列表（名称 + 人数/队数），底部可返回；数据缺失时回退双人对决。
- **选人进度** — 标题显示「请第 N 位选择角色（已选 x / 总数）」，副标题提示选人结束后随机分配座位与先手。
- **侧栏修复** — 修复右侧信息栏未横向填满导致的空档；提示框上移至阶段行之后，4 人局不再被折叠裁切。
- **拖放判定统一** — 移除 UI 层重复的目标合法性逻辑，拖放预览与落点统一走引擎判定。

## 🐛 Bug 修复

- **自伤/状态致死后死者仍可操作**——濒死者为当前行动玩家时，宣布死亡后错误地把流程交回其出牌阶段，导致死亡玩家界面仍可出牌/结束回合。修复后其回合立即结束，行动权移交下一名存活玩家；回合开始阶段被状态伤害致死同样覆盖。（含回归测试）
- **组队局仅剩一名幸存者时终局不显示队伍名**——按存活者所属队伍补齐「队伍X 获胜！」。
- **`dev_win` 开发者接口**——按存活者队伍正确结算组队局胜负。
- **侧栏提示框裁切**——4 人局侧栏高度紧张时提示框第三行被折出可视区，调整顺序后完整可见。
