# 《天光墟纪事》 Atlas

## v0.2.2-alpha 更新日志

**发布日期**：2026-10-29

新增护盾机制，并为「溯洄之境」牌池追加 3 名新角色（PM10、狄斯托利、卡丽茜），围绕护盾、状态层数与觉醒转化带来全新打法。

## 🎉 新内容

### 护盾机制

- 玩家新增「护盾」属性：存在时抵挡相当于护盾量的伤害，默认可抵挡物理/法术/灵魂全部伤害类型，但**无法阻止「失去生命」**。
- 除非描述另有限定，护盾持续无限、可叠加。
- 结算顺序：与伤害减免并存时**先算伤害减免，再扣护盾**。
- 玩家面板上护盾大于 0 时以青色显示「护盾 N」。

### 三名新角色（溯洄之境池）

| 角色 | 属性 | 技能概要 |
| --- | --- | --- |
| PM10 | 生命 + 冥暗 | 〔启泵〕开场获「进气」+2 护盾；〔气体交换〕判定阶段「进气」「排气」互切；〔增压〕弃牌额外切换并触发全体护盾或摸牌 |
| 狄斯托利 | 粒子 + 空间 | 〔我即真理〕弃牌叠「烈性炸药」强化普攻；〔我即武器〕觉醒将全部手牌转化为「高爆炸药」；〔毁灭当量〕限定技灵魂+物理混合爆发 |
| 卡丽茜 | 臆想 + 混沌 | 〔神经疗法〕普攻施加「毒素」；〔以毒攻毒〕对中毒目标额外附带法术伤害 |

### 新状态

- 「进气」「排气」：PM10 的形态标记，判定阶段开始互切并触发对应收益（「兴奋」增伤 / +2 护盾）。
- 「兴奋」：下次造成伤害 +100%（×2），触发后减一层，至多 9 层。
- 「烈性炸药」「高爆炸药」：狄斯托利的计数状态；前者使普攻额外造成 1 点物理伤害，后者供〔毁灭当量〕结算（X+2Y），至多 9 层。
- 「毒素」：出牌阶段开始时失去相当于层数的生命（每次至多失去 3 点），触发后清空，持续一回合。

## 🏗 引擎机制扩展

- `PlayerData` 新增 `shield` 与 `weapon_awakened` 字段；伤害管线在伤害减免之后加入护盾吸收（`hp_loss` 类型不受影响）。
- 新增 `gain_shield` 技能动作，技能/卡牌效果可直接给予护盾。
- 〔以毒攻毒〕的附加伤害通过 `antidote_proc` 标记防止自我连锁。
- 〔我即武器〕觉醒走 yes/no 询问弹层：拒绝后下个出牌阶段开始再次询问。

## 🖥 UI 调整

- 玩家面板新增护盾显示行。
- 技能选牌弹层支持〔增压〕〔我即真理〕弃牌与〔我即武器〕是/否询问的新标题与按钮文案。
- 未觉醒时〔毁灭当量〕在技能栏置灰（提示「未觉醒」）。
