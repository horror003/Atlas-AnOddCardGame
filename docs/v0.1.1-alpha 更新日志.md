| **雷雨**   | 时间 + 混沌 | 20   | 锁定技自动生成【电击1】，AoE 灵魂伤害打击触电目标，限定技召出【富兰克林之钥】          |
| **狄瑟**   | 粒子 + 空间 | 20   | 普攻改为 2 次 2 点物理，HP≤6 时觉醒降上限回血并解锁骰子 AoE 技能〖沙葬〗              |

| **奥比亚** | 粒子 + 混沌 | 20   | 首张普攻附带「失明」让目标下次伤害归零，主动技把手牌视作【窥视】进敌方判定区           |

### 新增 12 个角色技能

#### 雷雨

- 〖大气电压〗**锁定技**：出牌阶段开始时，将一张【电击1】加入手牌
- 〖尖端放电〗**主动技**（出牌阶段限一次）：场上存在带「触电」标记的玩家时才能发动；弃一张手牌，对场上所有带「触电」标记的玩家造成 2 点灵魂伤害
- 〖引雷〗**限定技**：将一张【富兰克林之钥】加入手牌（每局一次）

#### 狄瑟

- 〖扬沙〗**锁定技**：【普通攻击】默认改为 2 次 2 点物理伤害（同次出牌多段，不重复触发普攻被动）。正确通过 `_deal_damage` 走完整伤害计算链
- 〖星辉〗**觉醒技**：生命 ≤ 6 时触发，降 6 点上限、回 6 点生命、解锁〖沙葬〗
- 〖沙葬〗**主动技**（需觉醒解锁，每回合一次）：弃两张任意区域的牌 → 骰子判定 → 对全场造成 ceil(roll/2) 点物理伤害，自己受到减半

#### 古卢

- 〖止戈〗**锁定技**：受到其他玩家【普通攻击】伤害后，对来源施加一层「止戈」（上限 3 层）
- 〖仁慈〗**锁定技**：出牌阶段开始时摸 1 张牌 + 二选一：①失去 2 点生命；②对自己施加一层「止戈」

#### 李斯特

- 〖振荡〗**转换技**（出牌阶段限一次）：①弃 2 手牌 → 视作对他人使用【跳过】；②摸 2 牌 → 对自己加「跳过」。**强制按①→②→①顺序轮换**，第一次必①
- 〖喧闹〗**锁定技**：回合开始时，若手牌有【跳过】则全部弃掉并摸等量的牌。**同时禁止主动使用手牌中的【跳过】**

#### 奥比亚

- 〖光明之眼〗**锁定技**：每次出牌阶段打出的第一张【普通攻击】对目标附加一层「失明」
- 〖窥伺之眼〗**主动技**（每回合一次）：选一张手牌视作【窥视】进入敌方判定区

### 新增 3 张特殊牌（type=special）

**特殊牌规则**：只能通过角色技能或战场机制加入游戏，视同普通卡牌使用，但打出后**不进入弃牌堆，直接移除**。

| 卡牌                       | 目标                 | 说明                                                                                                         |
| -------------------------- | -------------------- | ------------------------------------------------------------------------------------------------------------ |
| **【电击1】**        | 其他玩家             | 造成 1 点灵魂伤害 + 持续 2 回合的「触电」标记                                                                |
| **【富兰克林之钥】** | 其他玩家（进预备区） | 目标回合判定阶段**两次排中判定**，第一次成功即中断；若两次都失败 → 失 8 点生命；带「触电」额外失 4 点 |
| **【窥视】**         | 其他玩家（进预备区） | 目标**出牌阶段开始**排中判定；失败时二选一：①失 3 点生命；②弃 2 张手牌                               |

### 新增 3 种状态效果

| 状态               | 触发               | 描述                                                                          |
| ------------------ | ------------------ | ----------------------------------------------------------------------------- |
| **「触电」** | 无                 | 持续 2 回合，雷雨〖尖端放电〗会自动锁定这些目标                               |
| **「失明」** | `on_deal_damage` | 造成伤害时伤害归零（-100%），触发后减一层；上限 9 层                          |
| **「止戈」** | `on_play_end`    | 造成伤害时 -1/层，叠加上限 3 层；**出牌阶段结束时自动清空自身所有止戈** |

## 🛠 开发者菜单（新）

<img width="1280" height="800" alt="51790cac23d0785330f185680cfc2b47" src="https://github.com/user-attachments/assets/132eb348-bf0f-44bb-9274-60b62f0994ee" />


新增 `scripts/dev_menu.gd`，仅在调试构建（`OS.is_debug_build()`）时由主场景创建，用于开发期直接操作游戏内状态。

- **入口**：顶栏「开发」按钮 + `F12` 快捷键，两者均可开关；右侧抽屉式面板，不遮挡牌桌主体。
- **玩家数值**：写入任意玩家的生命、生命上限、存牌值、摸牌值、「痂」。
- **区域编辑**：查看任意玩家手牌/装备栏/预备区/陷阱区的每一张牌并单张移除；从全卡库中挑牌加入指定区域。
- **状态效果**：给任意玩家施加任意状态（可指定层数、持续时间：永久/1-3 回合，受 `max_layers` 限制），或直接移除。
- **回合与流程**：强制设置当前回合玩家与阶段（会清空 pending 与伤害队列）；强制摸牌；预设下一次判定结果（强制成功/失败/骰子 1-6）；宣布玩家死亡或胜利。
- **牌堆**：查看三个牌堆数量与抽牌堆顶部 8 张；洗牌抽牌堆；把任意卡牌置入抽牌堆顶。
- **内部状态**：只读展示 `mode`、`phase`、`current`、`pending.kind`、伤害队列长度及各玩家资源摘要。
- **其他**：热重载 `data/*.json`、重启本局、导出当前战斗日志到 `user://dev_logs/`。

所有写操作统一经 `game.gd` 新增的 `dev_*` 接口执行，并写入战斗日志（前缀【开发者】），便于复现与回查。

## 🖥 UI 调整

- **手牌区自动换行并撑满高度** — 手牌由单行横向滚动改为 `HFlowContainer` 自动换行；卡牌高度按手牌区实际高度与行数动态均分（72–260px），6 张以内一行铺满，超出后换行并自动压缩；卡牌描述改为自动折行，长描述不再被横向裁切。
- **状态改为状态栏内点击查阅** — 玩家面板顶部状态行中的状态词条（含层数）、「痂」、「濒死」、「死亡」改为富文本链接，点击即在弹窗中显示名称与效果说明；同时从属性栏右侧移除原有的状态按钮与濒死按钮，信息行只保留属性与装备。
- **预备区卡名可点击** — 预备区中的牌名同样改为富文本链接（如【窥视】、【富兰克林之钥】），点击查看该牌的完整描述，无需再翻规则文档。
- **面板拖放与点击保留** — 顶部说明文本改为自定义 `StatusLabel`（`mouse_filter = PASS`）：链接点击由富文本处理，空白与普通文字区域的点击会冒泡到玩家面板用于选目标；同时把拖放判定转发给玩家面板，手牌拖到文字区域仍可正常使用/指定目标。

## 🏗 引擎机制扩展

1. **special 卡牌类型** — 新增卡牌类型 `special`，打出后由统一入口 `_resolve_card_after_play()` 根据 type 判定进弃牌堆还是直接移除。所有现有 `_to_discard(card_id)` 位置改为调用此函数。
2. **多段判定（multi_judge）** — `_run_judge` 扩展支持 `multi_judge` 配置：连续执行 N 次判定，成功可配置中断（`interrupt_on_success: true`）。全部成功执行失败效果。【富兰克林之钥】首次使用此机制。
3. **出牌阶段判定（trigger_phase=play_start）** — 延时判定牌的 `judge` 字典可声明 `trigger_phase`。`play_start` 类型的牌不在常规判定阶段结算，而是出牌阶段开始时由新入口 `_run_play_start_judge()` 单独处理。
4. **条件扣血（conditional_deal_damage）** — 判定动作里新增 `conditional_deal_damage` 类型：只有目标带有指定 `condition_status` 时才执行伤害。
5. **选择式判定（prompt_choice）** — 判定动作里新增 `prompt_choice` 类型：判定失败后进入 SKILL_PICK 模式让玩家在多个带 label 的选项按钮中选一个执行。
6. **`on_play_end` 状态钩子** — 新增出牌阶段结束的状态触发钩子 `_trigger_on_play_end_statuses()`，所有 `trigger: "on_play_end"` 的状态在 `ui_end_play_phase` 调用时清空。「止戈」首次使用。
7. **伤害乘算机制** — 「失明」伤害归零通过在乘算阶段前强制置零实现，不污染原有的 `damage_bonus` 加算体系。
8. **觉醒系统** — `player_data.star_brilliance_awakened` 字段跟踪狄瑟是否觉醒；每回合开始检查 HP ≤ 6 触发〖星辉〗，觉醒后自动把〖沙葬〗加入 `skill_ids`。技能选择界面狄瑟仍展示三个技能，沙葬默认灰显"（未觉醒）"；HP≤6 触发后自动解锁。
9. **限定技每局追踪** — 所有 `skill_type: "limited"` 的技能通过 `player_data.limited_used` 字典追踪使用状态。
10. **特殊牌 zone 字段** — 特殊牌（以及所有类型的延时判定牌）可声明 `zone: "reserve"`，打出时自动进目标对应区域，不进弃牌堆。`_resolve_played_card` 统一处理。
11. **强制形态轮换（oscillation_mode）** — 转换技通过 `player_data.oscillation_mode` 字段强制记录当前形态，第一次发动必①，每次发动后自动翻转。

## 🐛 Bug 修复

### 引擎兼容性修复（Godot 4.7）

- **`String(int)` 构造函数签名不匹配** — Godot 4.7 严格模式下 `String(123)` 直接解析失败。修复：全部改成 `str(123)`
- **`:=` 推断 Variant 返回类型** — GDScript 4.7 对 Variant 返回类型的 `:=` 推断会触发「类型从 Variant 推断」警告（被视为错误）。修复：显式声明 Dictionary/Array 类型
- **`Array[String].join()` 不存在** — Godot 4.7 的 typed Array 没有 `.join()` 实例方法
- **`String.join()` 不是静态方法** — Godot 4.7 里 String 没有静态 join
- **`PackedStringArray.join_delimiter()` 不存在** — Godot 4.7 里也找不到这个 API
- **最终方案** — 所有字符串拼接统一改成手动 for 循环 + `+=`，不依赖任何 Godot API
