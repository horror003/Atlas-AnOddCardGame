# 《天光墟纪事》 Atlas

## v0.2.0-beta 更新日志

**发布日期**：2026-10-27

基于 v0.2.0-alpha（多人对战），首次将游戏移植到 Android 触屏设备。桌面版体验完全不变。

## 📱 移动端适配

### 布局

- **基准分辨率 1280×720 + expand 拉伸**：任意屏幕比例下内容自动铺满，横屏锁定。
- **刘海屏安全区**：读取系统安全区，自动避开挖孔/圆角遮挡。
- **动态玩家面板**：2 人 1×2、3 人 1×3、4 人 2×2；4 人局面板自动紧凑化（属性/装备/技能合并一行），多状态、满预备区也不再挤压日志区。
- **触控目标放大**：底部操作按钮、弹层按钮短边 ≥56 逻辑像素，面板内小按钮同步放大，字号整体提升一档。
- **日志区保底高度**：修复面板内容增多时日志被压到只剩两三行的问题。
- **侧栏防溢出**：信息栏文本全部自动换行并裁剪在面板内，不再画出屏幕右缘。

### 输入交互

- **两段式出牌**：触屏禁用拖拽（与滚动争抢），点选手牌→点目标面板即可；桌面版保留拖拽。
- **长按看说明**：技能按钮长按 450ms 弹出说明（桌面版仍用悬停提示）。
- **返回键逐级取消**：说明弹层 → 选技能 → 选目标 → 事件展示，逐层关闭而不是直接退出游戏。
- **切后台回来自动刷新**界面状态。
- 启动器编辑器入口在移动端自动隐藏。

### 桌面模拟调试

设置环境变量 `ATLAS_MOBILE=1` 可在桌面以移动端布局运行，方便截图验证。

## 🏗 工程链路

- **Android 导出链路打通**：JDK 17 + Android SDK（platform-tools / android-35 / build-tools 34）+ Godot 4.7.2 导出模板，headless 命令行一条命令出包。
- **导出预设** `export_presets.cfg`：arm64-v8a、包名 `com.horror003.atlas`、沉浸式全屏、无网络权限需求；debug 包用编辑器默认调试签名。
- **ETC2/ASTC 纹理压缩**导入已开启（移动端必需）。
- Steam 版 Godot 为自包含模式，编辑器设置位于安装目录 `editor_data/` 下（与 %APPDATA% 无关），排障记录见交接文档。
