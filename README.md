# Welcome to Atlas. 

总之这是一个很简陋的卡牌游戏，以godot为开发平台。
目标是做成类似三国杀那样的多人联机战斗。

创意来源自本人初高中时期在学校不务正业写小说所构建的世界观。  
那会子用作业纸撕开成小张或者便签来充当卡牌，在学校（尤其是某些大型考试前，比如中考和高考）跟同学玩的不亦乐乎（（（

于是也便有了这个游戏的雏形。
